# URL Shortener

A FastAPI service that creates short URLs, redirects visitors, counts visits,
and logs successful redirect requests with the client IP and timestamp.

## Requirements implemented

- `POST /shorten` accepts an `original_url` and returns a short code.
- `GET /{short_code}` responds with a temporary redirect and increments the
  visit count.
- `GET /stats/{short_code}` returns the visit count.
- URLs are persisted with an original URL, unique short code, creation time,
  and click count.
- Redirect logging is centralized in middleware.

Scalability work is intentionally not included yet.

## Run locally

The included `.env` uses a local SQLite file, so no database server is needed
for development:

```bash
python3 -m pip install -r requirements.txt
python3 -m alembic upgrade head
python3 -m uvicorn app.main:app --reload
```

The API is then available at `http://localhost:8000`, with interactive
documentation at `http://localhost:8000/docs`.

`alembic upgrade head` creates or updates the schema to the latest migration.
It creates `url_shortener.db` in this project directory on the first run.

For PostgreSQL later, replace `DATABASE_URL` with a reachable database URL,
for example:

```text
DATABASE_URL=postgresql+psycopg://USER:PASSWORD@localhost:5432/url_shortener
```

## Database migrations

The initial migration is in `migrations/versions/`. Use these commands when
the model changes:

```bash
python3 -m alembic revision --autogenerate -m "describe the schema change"
python3 -m alembic upgrade head
```

Review an autogenerated migration before running it, then commit it alongside
the model change. To revert the most recently applied migration during local
development, run `python3 -m alembic downgrade -1`.

## Test

```bash
python3 -m pytest -q
```

Tests use an isolated in-memory SQLite database, so they do not need a local
PostgreSQL server.
